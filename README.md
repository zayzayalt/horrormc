# HorrorMC Discord Bot

Scaffold for a Discord bot that includes moderation features, an application system, ticketing, and fun/games commands.

Setup

1. Copy `.env.example` to `.env` and fill values.
2. Install dependencies: `npm install`.
3. Start: `npm start`.

This repo provides a modular command layout and a simple SQLite persistence layer. Extend commands in `src/commands` and utilities in `src/utils`.
